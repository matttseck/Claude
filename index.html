Cloud Sync

Connected & syncing in real time
Set up free real-time sync between your devices:
  1. Go to Firebase Console and create a new project (no Google Analytics needed)
  2. Go to Build → Realtime Database → Create Database, pick any region and start in test mode
  3. Open the Rules tab, replace everything with {"rules":{"expenses-data":{".read":true,".write":true}}} and click Publish (this stops test mode from expiring)
  4. Open the Data tab and copy the URL at the top (it looks like https://your-project-default-rtdb.firebaseio.com)
  5. Paste that URL below and click Connect. Then copy the share link that appears and open it on the other device.
